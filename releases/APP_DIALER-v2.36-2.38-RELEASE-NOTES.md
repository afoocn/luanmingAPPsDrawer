# 峦鸣抽屉 · APP Dialer 更新说明（v2.36 – v2.38）

> 合并版本：将 v2.36（持久化缓存）、v2.37（缓存图标尺寸修复）、v2.38（拼音表补漏字）三版合并发布。
> 适用包名：`com.fengnian.folderdrawer`（APP「峦鸣抽屉」）

## 概述

APP Dialer 是一个轻量「应用启动器」：在桌面快捷方式或主界面卡片打开后，弹出全屏半透明拨号盘，输入 **T9 数字** 或 **QWERTY 字母**，即可按「拼音首字母 / 拼音全拼 / 英文名」实时模糊匹配已装 App，点击图标立即启动。本次合并发布的重点，是把「冷启动很慢」和「缓存图标变形 / 个别 App 搜不到」几类问题一并根治。

---

## 一、v2.36 — APP Dialer 已装应用「持久化缓存」

**问题来源**：原来只有进程内存缓存，App 进程被杀（很久不打开）后就清空，下次冷启动仍要逐个读取已装 App、提取图标、计算拼音，很慢很费时。

**本次新增**：

- **缓存落盘（Room）**：把「仅内存」缓存升级为写入手机存储（表 `dialer_app_cache`，存包名 / 名称 / 拼音 / **图标位图** / 图标包 id）。进程被杀、隔很久再开，直接读盘秒显，不再逐个扫包、提图标、算拼音。
- **自动刷新**：监听系统 `PACKAGE_ADDED` / `PACKAGE_REMOVED` / `PACKAGE_CHANGED` 广播，去抖后自动重建写盘——新装 App 立刻可见、卸载的不残留，无需手动干预。
- **设置页新增「缓存管理」区块**（APP Dialer 设置内）：
  - **启用 APP Dialer 缓存** 总开关（关闭 = 不读写盘、每次实时读；关闭时自动清掉磁盘缓存）
  - **更新缓存** 按钮（手动全量重建写盘）
  - **清除缓存** 按钮（带二次确认，防误触）
- **图标包联动**：缓存记录当时的图标包 id，切换图标包后自动判定失效并重建刷新。
- 数据库 `version 13 → 14`，新增迁移建表（非破坏性，不影响现有数据）。

## 二、v2.37 — 修复缓存图标不随「图标大小」设置变化

**问题来源**：缓存图标之前固定以 96dp 栅格化，与你设置的「图标大小」无关；且改了尺寸后缓存不会自动重建，看到的是旧尺寸 / 旧样式的缓存图，与实时渲染不一致，显得「显示不完整」。

**本次修复**：

- **缓存按你的图标尺寸生成**：`drawableToBytes` 改为按 `DialogSettings` 的「图标大小」渲染缓存位图（下限 96dp 保清晰，封顶 192dp 控体积），缓存与设置一致、显示 1:1 不失真。
- **修正位图密度**：解码回 `BitmapDrawable` 时补上 `density`，缩放像素精确、不被二次拉伸。
- **改图标大小自动重建缓存**：设置页拖动「图标大小」后，去抖 800ms 自动重建缓存（避免拖动时反复全量扫描）。图标包变更仍由失效判定在下次打开时自动重建。

## 三、v2.38 — 修复「小宇宙」按 999 搜不到

**问题来源**：内置拼音首字母表（零依赖手写常用字表）漏了「宙」字，导致「小宇宙」的拼音首字母被算成 `xy`（应为 `xyz`），T9 下变成 `99` 而非 `999`，`match("99", "999")` 不命中 → 搜不到。

根因本质是：该拼音表只是「常用字 + App 名高频字」子集，**任何名称含表外汉字的 App 都会丢失对应首字母**，导致 T9 / 拼音搜不到——属系统性局限，非个例。

**本次修复**：

- 把「宙」补进字表 z 组（`RAW2`），「小宇宙」首字母恢复为 `xyz → 999`，T9 按 `999`、QWERTY 按 `xyz` 均可命中。

> 提示：若其它 App 也搜不到，多半同因（字表缺字）。可再做一次「扫描已装 App 名称里不在字表的汉字」审计，批量补齐高频缺字。

## 如何开启与使用

1. 全局设置 → 开启「启用 APP Dialer」（或在主界面 APP Dialer 卡片点铅笔进设置）。
2. 主界面会出现「APP Dialer」虚拟卡片，点击即弹出拨号盘；也可在设置里「创建 APP Dialer 快捷方式」钉到桌面。
3. 拨号盘内：
   - **T9 模式**（默认）：按数字键，如 `999` → 拼音首字母含 `xyz` 的 App；`9436` → 拼音含 `wxj` 等。
   - **QWERTY 模式**：在设置「键盘模式」切换，直接输字母。
   - 支持子串（模糊）匹配：任意位置命中即可，不限于首字符。

## 缓存管理（在 APP Dialer 设置页）

| 开关 / 按钮 | 作用 |
| --- | --- |
| 启用 APP Dialer 缓存 | 总开关；关掉即不读写盘、每次实时读取，并自动清掉磁盘缓存 |
| 更新缓存 | 手动全量重新扫描已装 App 并写盘 |
| 清除缓存 | 删除磁盘缓存（二次确认防误触）；下次打开会重新构建 |

## 已知说明 / 限制

- **缓存体积**：图标一并缓存，几百个 App 约占用几 MB ~ 十几 MB 内部存储；切图标包后首次打开会触发重建。
- **拼音表覆盖**：内置表为常用字子集，极生僻字 / 新造词可能仍搜不到（v2.38 已修「宙」；其余缺字可按需补）。
- **圆形蒙版启动器**：桌面快捷方式图标在部分启动器下方形四角可能露极薄白边（启动器蒙版行为），非 App 缺陷。
- **Release 安装包**：APK 不随源码入库（`.gitignore` 屏蔽 `*.apk`），请从本 Release 的附件下载 `app-release-v2.38.apk`。
