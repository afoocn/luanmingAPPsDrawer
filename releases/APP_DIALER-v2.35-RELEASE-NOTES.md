# 峦鸣抽屉 · APP Dialer 功能完整更新说明（v2.16 → v2.35）

> 本文档汇总「峦鸣抽屉」从 **v2.16** 首次引入 APP Dialer，到 **v2.35** 的全部功能与迭代记录。
> 当前最新版本：**v2.35**（versionCode 120）。

---

## 一、APP Dialer 是什么

APP Dialer 是「峦鸣抽屉」内置的一个**轻量应用启动器**。它在桌面或应用内随时呼出一个**全屏半透明拨号盘**，你只需输入 T9 / QWERTY 键码，就能按 **拼音首字母 + 英文原名** 实时模糊匹配手机里已装的应用，点一下图标直接启动。

适合这样的场景：桌面上图标太多懒得翻、又不想装臃肿的第三方启动器；或单手操作想快速拉起某个 App。

### 核心特性
- **全屏半透明弹窗**，视觉与主弹窗（抽屉）一致，支持毛玻璃、背景色/位置/动画等全局弹窗设定。
- **实时模糊匹配**：中文按拼音首字母（如「微信」→ `wx`，「哔哩哔哩」→ `blbl`），英文按原名；任意位置子串命中，边打边筛。
- **T9 / QWERTY 双键盘模式**可切换（设置内）。
- **独立宽度与按键自定义**：弹窗水平边距、按键高度/宽度、行/列间距均可单独配置，不干扰普通抽屉弹窗。
- **锁屏即退出**：拨号盘弹窗在息屏后自动关闭，亮屏不再残留。
- **可钉桌面 / 可被手势软件调用**：作为「特殊抽屉」（id = -2，不写数据库）并入抽屉体系，所有入口走已验证的稳定路由，手势软件（如 MyGesture）添加快捷方式不再假死。

## 二、如何开启与使用

1. **开启**：全局设置 → 「启用 APP Dialer」开关（默认开）。关闭后主界面卡片隐藏、功能停用、桌面旧快捷方式失效。
2. **主界面入口**：主列表末尾的「📞 APP Dialer」卡片，点击直接弹出拨号盘；卡片带「钉桌面 / 编辑（铅笔）/ 删除」三个按钮，风格与普通抽屉卡片统一。
   - 钉桌面：把拨号盘快捷方式放到桌面。
   - 编辑：进入 APP Dialer 专属设置页。
   - 删除：弹出「是否关闭 APP Dialer 功能？」确认框，确认即关闭总开关并移除卡片。
3. **专属设置页**（主界面卡片铅笔按钮，或全局设置里的「打开 APP Dialer 设置」）：键盘模式、是否记忆上次结果、输入栏/结果区高度、每页应用数、图标大小、名称字号/颜色/是否显示/是否单行、弹窗水平边距、按键高/宽/行/列间距；并可**自定义桌面快捷方式图标**（支持选图标包）、**指定图标主题（图标包）**、**创建 Dialer 快捷方式**。
4. **手势 / 自动化软件**：通过系统「应用快捷方式」机制被发现与添加（需开启功能）。

## 三、更新历程

### v2.16 — 首次新增 APP Dialer
全屏半透明弹窗 `AppDialerActivity`：T9/QWERTY 拨号盘，拼音首字母 + 英文原名实时前缀匹配已装 App，点图标启动。图标经全局图标包渲染，弹窗背景/位置/动画/间距全部读取全局弹窗设定。

### v2.18 — 匹配模型升级为子串（模糊）匹配
内置零依赖拼音首字母表（覆盖 GB2312 一级常用字 + App 名高频字），由前缀匹配改为**子串（模糊）匹配**，任意位置命中。

### v2.20 — 设置独立 + 结果区/图标自定义
全局设置新增「APP Dialer」分区，含键盘模式、是否记录上次结果，以及 8 项结果区/图标自定义（输入栏高、结果区高、每页个数、图标尺寸、名称字号/颜色/显示/单行）。

### v2.24 — 并入「特殊抽屉」体系（修复手势软件假死根因）
将 APP Dialer 作为「特殊抽屉」（id=-2，不写库）并入现有抽屉 id 空间，所有入口统一经 `CollectionLauncherActivity`（`folderdrawer://collection/-2`）稳定路由，彻底绕开此前 `DialerLauncherActivity` 在小米 HyperOS/MyGesture 等 ROM 上半透明弹窗 attach 失败导致的「调用假死」。

### v2.25 — 修复手势软件「添加快捷方式」卡死 / 添加不成功
`CreateShortcutActivity` 的拨号盘结果回调改为与抽屉一致的协程 + try/catch 兜底，补全 intent 字段与图标尺寸，永不卡死。

### v2.26 — 弹窗宽度独立 + 浅色模式可读性 + 汉字补全 + 卡顿修复
- 拨号盘弹窗宽度独立于全局弹窗配置（`dialer_margin_horizontal`）。
- 新增 5 项按键自定义（高度/宽度/行间距/列间距）。
- 拼音表扩充 `RAW2` 字表，修复「哔哩哔哩」等因缺字无法匹配。
- 修复主界面点卡片弹出的卡顿（模糊在 `onCreate` 预开，不在动画中途开）。

### v2.27 — 浅色模式可读性修复 + 去横线
文字色改为**按卡片实际底色计算对比度**，根除「浅底白字」看不清；去掉按键与结果区之间的分隔横线。

### v2.28 — 桌面图标自定义（图标包）+ 设置独立页 + 总开关 + 去分割线
- 桌面快捷方式图标可像抽屉一样自定义并指定图标包。
- 新建 `DialerSettingsActivity` 专属设置页，主界面卡片加铅笔按钮进入。
- 全局设置新增「启用 APP Dialer」总开关（开→显示卡片且可用；关→隐藏并停用）。
- 所有卡片上的分割横线全部移除。

### v2.29 — 修复自定义桌面图标「一圈颜色」
`drawableToAdaptiveBitmap` 重写：自适应图标（`AdaptiveIconDrawable`）画满整张画布不再填主色；其它图标放大安全区把主色圈压到最薄。抽屉与拨号盘自定义图标共用，一并受益。

### v2.30 — 改用 `createWithAdaptiveBitmap`（未达预期，回退）
尝试根治系统对普通位图套的圆形底色蒙版，改为自适应位图；但触发更宽的自适应蒙版底色，未达预期。

### v2.31 — 圆形裁剪 + 锁屏即退出（用户不喜欢变圆，后回退）
- 把自定义图标裁成圆形以填满圆形蒙版（消除底色圈），但改变图标形状。
- 新增 `ACTION_SCREEN_OFF` 监听，锁屏即 `finish()` 退出拨号盘（保留至今）。

### v2.32 — 回退到 v2.29 方形处方
用户不喜欢图标变圆，回退并改进 v2.29 方形不裁圆方案：自适应图标画满、位图画满画布、主色仅在透明像素极小露出，圈色最薄且保留原形状。

### v2.33 — 自定义图标「圈色」改为白色
自定义图标透明边距露出的兜底色由 APP 主色改为 `Color.WHITE`（中性，浅色壁纸上更隐形）；主动设置的 `iconColor` 整块底色不受影响；内置键盘/汉堡图标保持彩色底（白底会看不见）。

### v2.34 — 主界面卡片加删除按钮（关闭总开关）
APP Dialer 虚拟卡片补齐「删除」按钮，与上方普通抽屉卡片风格统一（钉桌面/编辑/删除三按钮）。删除按钮弹出「是否关闭 APP Dialer 功能？」，确认即关闭总开关并移除卡片。

### v2.35 — 长按菜单（动态快捷方式）图标去「背景色」
动态快捷方式（长按「峦鸣抽屉」应用图标弹出的菜单）单独改用自适应图标，消除启动器额外套的圆形底色板；桌面钉的快捷方式保持 v2.33/2.34 的方形白圈处方不变。

## 四、已知限制 / 说明
- **圆形蒙版启动器**：在强制圆形蒙版的启动器下，方形自定义图标四角可能仍露极薄白边（启动器蒙版行为，非 App 可控）。绝对无圈需改用圆形裁剪或默认键盘图标，由用户权衡。
- **图标包自适应图标**：若自定义图标本身是图标包自适应图标（自带背景层），长按菜单会显示其图标包背景色——那是图原本身体现，非启动器额外底色。
- **品牌罗马字**：匹配按「拼音首字母 / T9 数字」模糊子串，直接打品牌罗马字（如 `bilibili`）不在覆盖范围内，请打首字母。
- **Release 资产**：本仓库 `.gitignore` 忽略 `*.apk`，安装包不随源码入库；APK 请在 Release 页面下载。
